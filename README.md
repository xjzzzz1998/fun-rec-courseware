# FunRec 推荐系统入门课件

这是根据 [datawhalechina/fun-rec](https://github.com/datawhalechina/fun-rec) 的 `web_project` 整理的中文入门课件，面向只有基础 Python 背景的初学者。

## 在线访问

课件已经通过 GitHub Pages 发布：

<https://xianjiezeng.github.io/fun-rec-courseware/>

## 课件内容

- Python、Vue、HTTP 和 FastAPI 基础
- 用户、电影、评分和 Redis/PostgreSQL 数据
- 前端请求、后端 API 和 Docker 工程
- 推荐系统整体架构
- 离线流水线和在线推荐请求
- 召回、YoutubeDNN、DeepFM 精排和重排
- 冷启动、UCB、多样性策略和降级逻辑
- 可折叠源码、逐段解释和 GitHub 原代码链接
- 14 天学习计划和动手实验

## 使用方式

直接打开 `index.html` 即可阅读。课件不依赖后端服务，搜索、代码折叠、学习进度和手机端布局都在浏览器中完成。

搜索框支持：

- 输入关键词后自动高亮
- 点击 ↑ / ↓ 切换上一个或下一个命中
- `Enter` 跳到下一个命中
- `Shift + Enter` 跳到上一个命中
- `Esc` 清空搜索

## 更新课件

修改本地 HTML 后，将新的文件命名为 `index.html`，上传到 GitHub 仓库根目录并提交。GitHub Pages 会自动重新构建，网址保持不变。
